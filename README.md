# AIO 用户与权限插件 / AIO User & Permission Plugin

提供用户、角色、权限声明和请求授权边界，运行数据按租户隔离。客户端分别贡献“系统 / 系统管理 / 用户管理”和“系统 / 系统管理 / 角色管理”两个叶子页面。

Provides user, role and permission declarations and a request authorization boundary, with runtime data isolated per tenant. The client contributes two leaf pages: “系统 / 系统管理 / 用户管理” (System / System Admin / User Management) and “系统 / 系统管理 / 角色管理” (System / System Admin / Role Management).
