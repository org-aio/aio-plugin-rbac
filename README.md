# AIO 用户与权限插件 / AIO User & Permission Plugin

提供用户、角色、部门、岗位、权限声明和请求授权边界，运行数据按租户隔离。客户端贡献“系统 / 系统管理”下的用户、角色、部门和岗位页面。

Provides user, role, department, post and permission declarations and a request authorization boundary, with runtime data isolated per tenant. The client contributes user, role, department and post pages under “系统 / 系统管理” (System / System Admin).
